# Карточная игра Elemental Duelist

Это простая карточная игра для одного игрока, где игрок играет против компьютера.

## О проекте

- Игра реализована как одиночная карточная игра против компьютера;
- Проект написан с использованием Unity C#.

## Возможности

- Игрок против искусственного интеллекта;
- Кастомизация карт;
- Простое управление и интерфейс;
- Возможность перезапуска игры.

## Как запустить

1. Перейдите в раздел [Releases](https://github.com/xJaSzyy/CardGame/releases) на GitHub;
2. Скачайте последний релиз;
3. Запустите скачанный `.exe` файл;
4. Следуйте инструкциям в игре.

## Управление

- Используйте мышь/клавиатуру для выбора и сброса карт.
- Ход компьютера выполняется автоматически.
